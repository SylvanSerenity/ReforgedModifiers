# Reforged Modifiers

Reforged Modifiers adds equipment modifiers based on [Terraria's modifiers](https://terraria.wiki.gg/wiki/Modifiers).

Based on the [Modifiers](https://github.com/CursedFlames/Modifiers) and [Remodifier](https://github.com/MCTeamPotato/Remodifier) mods.

# Dependencies

* NeoForge or Fabric
* [Cloth Config API](https://github.com/shedaniel/ClothConfig/)

# Compatibility

The following mods are supported and optional:

* [Curios API](https://github.com/TheIllusiveC4/Curios)
* [Artifacts](https://github.com/ochotonida/artifacts)
